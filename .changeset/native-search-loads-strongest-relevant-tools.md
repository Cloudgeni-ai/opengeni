On native tool-search routes, a search whose ranking finds relevant tools but no single clear best (an exact tie, or no resource word in the top tool's name and capability sentence) now loads the strongest relevant tool and any tied with it, within the limit, instead of returning nothing. A relevant tool has the query's operation, when it names one, and a query resource word in its own name or capability sentence or among its connected integration's own words (words several of its tools use, but none of its tool names). A query that shares only a verb with a tool, or matches nothing, still loads nothing, and generic dispatch routes keep listing compact candidates. Ranking reads past the account line tool descriptions get when a person has several accounts of one connector, so those tools rank as they do with one account; the descriptions themselves are unchanged. "check" counts as a read operation. The other-connected-accounts notice now also follows the turn's first load by exact names that reaches one of several connected accounts.
