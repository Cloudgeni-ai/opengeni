Compute now alerts on what its incidents look like. compute-control counts each host's fresh registrations and its wake and placement refusals (a host full), the leader reports each host's epoch (`compute_fleet_host_epoch`, whose changes mean its agent restarted), and the chart adds OpenGeniCompute alerts for a host agent restarting, a host refusing wakes, a host unreachable, the fleet full with no spare memory, and failing sandbox creates. Their thresholds are under `computeControl.alerts` (`spareMemoryMib`, default 4096, 0 turns FleetFull off; `createFailureRatio`, `createMinimum`, `agentRestarts`, `refusedWakes`). The compute-control ServiceMonitor moves to its own template, so a render of only the core workloads' monitoring (`--show-only templates/servicemonitor.yaml`) no longer includes it. The GCP compute Terraform module ships host journals to Cloud Logging through serial-port logging (`journal_to_cloud_logging`, default on). A project whose organization enforces `compute.disableSerialPortLogging` must set it to false, or new hosts fail to be created.
