New `@opengeni/react/automation-model` entry: how automations read to people (when one runs, its next run, the list order, what a run did, the first message of a chat that creates one) with no React DOM, for hosts that draw their own screens such as React Native. `automationAgentOpeningMessage` is also exported from `@opengeni/react/automations`. The Opengeni phone app uses it for its new Automations screens.
