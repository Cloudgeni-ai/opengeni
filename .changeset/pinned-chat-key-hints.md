Holding ⌘ (Ctrl on Windows and Linux) for a moment in the desktop app shows each pinned chat's ⌘1 to ⌘9 key in place of its time, so the shortcut is discoverable. The numbers follow the order the Pinned section shows. Browsers keep ⌘1 to ⌘9 for their own tabs, so the hint appears only where those keys work.
