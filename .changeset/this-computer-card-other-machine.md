The "Your computer" conversation card no longer looks done when the ready computer may not be the one the person means. Outside the desktop app, a ready computer on another system than this browser's is named as another computer, and connecting this device stays the main action. When the host offers no way to connect this device, the card keeps the host's own text for it beside the ready line instead of showing a check mark. On a phone, a ready computer still completes the card.
