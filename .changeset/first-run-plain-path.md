A smoother first run in the chat app. Adding credits from a chat or the new-chat page returns to that page with the draft kept and a short "You added $N in credits" confirmation, instead of landing in organization billing; embeds keep their existing new-tab checkout. With no usable credit, the new-chat page says so once in plain words ("Add credits to start chatting", or "Add credits to use this model" when the credit left covers only other models), with the one action that fixes it, and the failed-turn and credit-refusal notices say "Add credits", use the same wording from the organization's balance, and can top up in place through a new optional `onAddCredits`; `CreditRefusalNotice` takes optional `accountId` and `canReadBilling` for that balance check. The voice control renders nothing until a voice model can run, instead of a disabled button explaining which provider to connect. `ListRow` sets `aria-controls` only while its panel is rendered. In the web app, someone who chooses "Run agents in the cloud" gets an organization named after them (renameable in Organization settings or by asking in chat) instead of the "Create your organization" form, which the developer path keeps; and the model step lists Opengeni credits and the subscription providers first, with OpenAI, Azure OpenAI, OpenRouter, Opper and Vercel AI Gateway one click away under "Use your own provider account".
