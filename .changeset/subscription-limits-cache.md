Subscription accounts and their usage limits no longer have to reload from scratch every time you come back to them. `useCodexAccounts` and `useSuperGrokAccounts` now share reads per `client` object: readers mounted at the same time share one request, failed reads are never served as cached data, and a pin or activation re-reads every mounted list for that workspace even when the component that made it has unmounted. New `OpenGeniProvider` prop `retainReadsAcrossMounts` (default off) keeps those reads across navigation, so a remount renders the last accounts at once and re-reads them in the background; retained reads are dropped when `client` changes or the provider unmounts. Without it nothing is served to a later mount. **Host action item:** set `retainReadsAcrossMounts` only if every signed-in person gets their own `client` object; leave it off when one client is reused across people. `useCodexAccounts().refreshUsage({ maxAgeMs })` reuses live usage readings only when every listed account was read within `maxAgeMs` and shares one provider read between concurrent callers, and the result exposes `liveUsageUpdatedAt` (the oldest account reading). No new exports.
