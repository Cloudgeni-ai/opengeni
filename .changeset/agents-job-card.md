Agents are job cards. The Agents list shows one status per agent (Working now, Ready, Needs PostHog, On call), what starts it and its last run, and one Ready-made list: opening a ready-made agent previews what it does, when it works and what it needs, and only Add agent adds it. An agent's page says when it works in plain sentences, with whose access each trigger runs as and when it last ran, and keeps its setup one click away in Settings. Add trigger starts from a few outcomes (an issue gets a label, a pull request opens, on a schedule, a mention), with other events one link away, a schedule can open a repository, and Automations no longer repeats the templates a ready-made agent already does.
