When something you can fix blocks the agent, such as your Chrome not being connected or a machine you haven't allowed this chat to use, the setup card now appears in the same reply. You no longer have to ask the agent how. If the agent needs your own Chrome and it isn't connected, a Chrome card shows one step at a time: connect this computer, add the Opengeni Browser extension, then continue.
