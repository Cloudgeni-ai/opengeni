The Models page now says what Codex placement actually does. When a workspace picks accounts automatically, its own Codex accounts and the organization's serve new work together, so the page no longer claims the organization's accounts are set aside, and connecting an account no longer asks to choose one pool or the other (that question used to pin the workspace to the organization's accounts and silently park every account connected later). A workspace explicitly set to use only the organization's accounts now asks, when someone connects an account, whether to use it together with the organization's or keep it unused.
