Computer tools may omit `computerSessionId` and `targetId` to keep working in the computer and window the agent used last, the way browser tools keep using the current tab. With nothing used yet in the turn, `computerSessionId` resolves to the session's most recently used live computer; a window must be named once. An action that opens a window makes that window the current one. `computer_act` also takes a bare element ref as a locator, including inside a batch. Fewer identifiers per step means fewer output tokens and faster steps.
