A browser or desktop placed on a session's own managed box stays reachable while that session routes to a Connected Machine. Sessions whose home is a machine used to follow the selected machine for every direct operation, so reopening such a browser failed with "home placement is unavailable" even though its box still existed. Requests for a controller placed on the managed box now go to that box, the same way they already do when no machine is selected.
