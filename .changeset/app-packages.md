Export an app as one package file and install it into another workspace as a new app with empty data (or the author's demo data). Adds the `app_export` and `app_install` agent tools, `exportAppPackage` and `installAppPackage` in the SDK, and Install app and Export app in the console. See docs/app-packages.md.
