An MCP server can now ask the person a question in the middle of a tool call (MCP elicitation, revision 2026-07-28, multi round-trip): a confirmation, a form to fill in, or a web page to open (URL mode, for example to sign in or pay). Model calls to third-party MCP servers declare that they can answer forms and pages; when the server answers `input_required`, the call pauses as an approval of the same call, the person answers in the approval card (possibly hours later, including in unattended runs), and the call is retried with the answer and the server's `requestState`. Declining is sent to the server too (`action: "decline"`), so it can release what it was holding and finish the call its own way; the model then sees the server's result followed by a note that the person declined. Pages to open must be plain `https` links; every surface shows the link's host, opens it in a new tab only on click, and Continue tells the server to check whether the step is done. The model only sees the call's final result. `session.requiresAction` approvals carry a new `elicitation` field, and `user.approvalDecision` takes `content`, which the API checks against the server's form (422 with the reason when it does not fit). The question shows on every approval surface: the session card (web and native, with the form or the page), the inbox (the question as the title; Allow for a confirmation, Open and Continue for a page, Answer for a form), phone push ("<server> asks: …"; pages and forms open the app) and private Slack cards (Allow for a confirmation, a link button and Continue for a page, a link to answer a form in Opengeni). Connector action records gain `input_round`, so a tool with an Ask policy or saved rule can be asked more than once and answered in a later worker attempt. New exports: the `McpElicitation*` schemas and helpers in `@opengeni/contracts` (also at `@opengeni/contracts/mcp-elicitation`), including `mcpElicitationKind` and `mcpElicitationUrlHost`, and their types in `@opengeni/sdk`; `InboxItem.serverQuestion` (`{ server, kind, url? }`); `ToolActionReview.question`; `sendApprovalDecision` accepts `content`; React `ApprovalSurface` renders the question and passes the answer to `onApprove` as its second argument, and `McpElicitationRequest` is exported from `@opengeni/react/session-ui`; React Native `ApprovalStrip`'s `onDecide` receives the answer as its third argument; `@opengeni/testing/mcp-elicitation-server` is a fake server for client tests. See `docs/mcp-elicitation.md`.
