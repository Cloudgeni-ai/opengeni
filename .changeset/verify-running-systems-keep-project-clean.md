Agents working in a sandbox or on a Connected Machine now finish changes to something already running on the running instance: the base sandbox instructions say to restart or reload the process that actually serves a change to a service, worker or scheduled job, exercise the real entry point and check what the user asked about, because unit tests alone do not show it works (asking first only when a restart could disrupt others). The same instructions now keep the agent's own scratch work out of the user's project: throwaway scripts and tests, caches, and browsers, runtimes or libraries installed only for its own checks go in a temporary directory outside the project and are removed when done, while tests the user asked for or the project expects still belong in it. Both are one clause appended to an existing line of the sandbox preamble (about 118 tokens), so sessions without a sandbox are unchanged. When the built-in browser cannot start because a machine has no Chrome or Chromium, its error now says to install one system-wide, where the browser tool finds it, and not to install a browser or its libraries inside a project folder.
