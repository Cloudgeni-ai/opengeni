Connecting a coding agent starts in the organization you last worked in, with everyday work selected (chats, files, apps and their data, automations, using secrets; never people, keys, billing or secret values), shown as Custom so every permission stays visible. The permission list has an Apps group for opening apps and changing their data. App data a connected agent writes is recorded as that connected agent (`agent:connection:<id>`) instead of as the person; the records still belong to the person.
