The Excel add-in manifest can name a store publisher and support page, for listing the add-in in Microsoft's add-in store: set `OPENGENI_OFFICE_ADDIN_PROVIDER_NAME` and `OPENGENI_OFFICE_ADDIN_SUPPORT_URL`. Without them the support link now points at the deployment's `/excel` page. The docs gain an Excel add-in guide that serves as the add-in's help page.
