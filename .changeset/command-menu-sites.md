The ⌘K / Ctrl+K command menu finds Sites in the current workspace. Typing still lists chats first, then matching Sites in a Sites group after them, by title, using the workspace's access-checked Site catalog, so people only see Sites they can open. With nothing typed it shows up to three recently active Sites. Choosing one opens it in the app's Site view, including in the desktop app; ⌘/Ctrl+Enter on the web opens it in a new tab. If Site search fails, the rest of the menu keeps working.
