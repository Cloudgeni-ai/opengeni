`npx opengeni connect` adds the Opengeni MCP server and a short `opengeni` skill to Claude Code, Codex, Cursor and VS Code with Copilot. The organization MCP server lists named tools for connected agents (`delegate`, `wait_for`, session, app, tool, Skill and Knowledge tools). `updateOrganizationMcpConnection` accepts `appDataAccess` and `defaultWorkspaceId`, and `access` is now optional.
