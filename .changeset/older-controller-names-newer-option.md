When a browser controller from an older release rejects an action's format, the agent is told which newer option the controller does not accept and what to use instead, that nothing ran, and that updating the Opengeni agent adds support, instead of being told to update a controller image that connected machines do not have. A test now fails when the browser action contract gains an option without naming it for older controllers.
