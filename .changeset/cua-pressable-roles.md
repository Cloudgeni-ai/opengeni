On macOS a computer-use batch step that names a button or link by exact name, when the control has the other of those two roles, now presses or checks the one element of that name and says which element it used, instead of waiting out its timeout and failing. A wait whose name appears only on an unrelated kind of element stops once the window settles. A computer action receipt lists such actions in its optional `roleStandIns`.
