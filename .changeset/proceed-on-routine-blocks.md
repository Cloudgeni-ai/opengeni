The agent finishes work when a routine local step is blocked instead of ending the turn with a question. It takes the conventional default and says so: it commits with a per-command identity when Git has none, branches from the repository's default or current branch when the requested base such as `main` does not exist, and treats steps an AGENTS.md reserves for people, such as maintainer agreement, as part of submitting work rather than of local changes on an unpushed branch. It still asks before destructive steps, steps outside the workspace, or steps that need authority it has not been given.
