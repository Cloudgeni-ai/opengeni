Connected tools that can do a task now win over a Connect card for an unconnected alternative. In the agent's integration catalog search, a service the person can already use in the chat comes before a same-category service they would still have to connect (Outlook Mail before Gmail for "read my email" when only Outlook Mail is connected), unless the request names the unconnected service. The per-turn connector availability notice now says that a configured but unavailable connector is needed only when the person named it or no loaded tool can do the task.
