Add `@opengeni/react/skills`, a packaged Skills page for any host: list, view, a folder editor with save and remove, version history and restore when the client can read them, and upload of a SKILL.md, a skill folder or a .zip. Also exports `@opengeni/react/ui/capability-page`, and `ConnectionInstalled` takes `title={null}`, an `aria-label` and a per-item `statusTone`. `SkillsPanel` takes `refusalCodes` to show a host relay's own refusal sentences.
