The mobile chat now shows the cards the web chat shows for long agent work. When the agent asks to use a machine you already connected, the card names it and offers Allow (or another machine), instead of only a link to open the chat on that computer. Goal changes, failed or skipped compaction, worker results, grouped machine updates and usage-limit notices get their own rows rather than plain dividers or nothing. The wording and grouping come from shared models that the web chat now uses too.
