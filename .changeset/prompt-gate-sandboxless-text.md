Configured agents without a sandbox or Connected Machine no longer receive instructions they cannot act on: editing or publishing sandbox files, workspace file links, sandbox paths, background-command acknowledgement and sandbox CLI lists. Site guidance stays, since Sites are created from inline HTML. The verification rule names a goal and its completion audit only when goals are on, so a session with compute but without goals also gets the shorter rule; sessions with goals and a sandbox or Connected Machine keep their exact prompt.
