Linux computer use accepts more key names: F1 to F24, Insert, PrintScreen, ContextMenu, ScrollLock and Pause, and a modifier pressed on its own, such as Super. A function key the X11 layout lacks (F13 to F24 on most layouts) is bound to a spare keycode for one complete press and restored afterwards. On GNOME Wayland, a named key that no group or level of the keyboard layout has is refused instead of being silently dropped. CapsLock and NumLock stay refused, because a lock left on silently changes later typed text. The first pointer action after observing a native Linux or macOS computer no longer fails as a stale frame when the screen has not changed: the frame of the screenshot an observation returns stays the helper's newest frame.
