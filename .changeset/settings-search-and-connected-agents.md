Settings can now be searched. A search field at the top of the settings rail finds any settings page you can use, and common settings inside them (Voice input, Create API key, Invite people, the Opengeni MCP server...), by name or by other words for them; Enter opens the best match and the arrow keys move through the results. Connected agents is now its own Organization settings page for every signed-in member, not only owners: it shows how to add the Opengeni MCP server to Claude Code, Cursor, Codex or any MCP client, then lists your connected agents. Older Developer links to Connect an agent or an agent's page open the new page.
