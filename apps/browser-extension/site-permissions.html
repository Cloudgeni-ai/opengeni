    Let {{product}} agents allow your camera, microphone, location and notifications on a site

    When an agent works in a tab in this Chrome profile, a site sometimes needs your camera, microphone, location or notifications, for example to test a video call. If you allow this, the agent can turn them on or off for the site open in a tab it opened itself, without asking you each time.

    • Only these four, and only for the exact site (for example https://meet.example.com) open in a tab the agent opened itself. Never for all sites, and never from your own tabs.
    • Every change is listed here and in the {{product}} extension menu, where you can remove it. Chrome's own site settings show it as set by an extension.
    • You can turn this off here at any time, which removes every change it made.

    Chrome asks you to confirm. Its wording covers more than {{product}} uses: {{product}} only ever changes the four permissions above, for the site in a tab an agent opened.
