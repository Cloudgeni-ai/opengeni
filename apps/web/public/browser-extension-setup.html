Connect this Chrome profile

The OpenGeni machine agent is ready. Chrome requires you to approve an extension once for each profile you want agents to use.

  1. Download and extract the extension.
  2. Open chrome://extensions, enable Developer mode, then choose Load unpacked.
  3. Select the extracted opengeni-browser-extension folder. The profile then appears in OpenGeni automatically.
Download OpenGeni Browser A future Chrome Web Store listing can replace this manual development install. Existing tabs are never attached until an agent explicitly uses this profile.
