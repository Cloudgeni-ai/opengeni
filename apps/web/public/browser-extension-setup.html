Connect this Chrome profile

The Opengeni machine agent is ready. Chrome requires you to approve an extension once for each profile you want agents to use.

  1. Open the Chrome Web Store listing in the profile you want to connect.
  2. Choose Add to Chrome and confirm the extension permissions.
  3. Open Opengeni Browser to check its connection and give this profile a label.
Install from Chrome Web Store The profile appears in Opengeni automatically. Existing tabs attach only when an agent uses them.
Install an unpacked development version
  1. Download and extract the extension.
  2. Open chrome://extensions, enable Developer mode, then choose Load unpacked.
  3. Select the extracted opengeni-browser-extension folder.
