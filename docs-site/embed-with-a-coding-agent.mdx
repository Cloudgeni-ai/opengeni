The `opengeni-client` skill teaches a coding agent how to add OpenGeni to your product. Install it, describe what you want, and let the agent build it.

## Before you start

1. Sign up at [app.opengeni.ai](https://app.opengeni.ai) (or [self-host](/guides/self-host)). If you choose **Add AI agents to my product**, setup gives you a key and a ready prompt, and you can skip to the prompt below.
2. Create a **full-access** API key in **Organization settings → Developer → API keys**.
3. Set three variables on your backend:

| Variable                   | Value                                                  |
| -------------------------- | ------------------------------------------------------ |
| `OPENGENI_API_BASE_URL`    | `https://app.opengeni.ai`, or your self-hosted API URL |
| `OPENGENI_ORGANIZATION_ID` | **Organization settings → General → Organization ID**  |
| `OPENGENI_API_KEY`         | The API key. Keep it on the server.                    |

## Copy this prompt

Paste it into Claude Code, Codex, Cursor, or any agent that can run commands in your repository:

```text
Add an OpenGeni agent to this product.

1. Install the OpenGeni integration skill:
     npx skills add Cloudgeni-ai/opengeni --skill opengeni-client --yes
   If that is unavailable, read
   https://docs.opengeni.ai/reference/opengeni-client-skill.md
2. Read the skill, then inspect this repository: auth, tenants, data routes,
   frontend, tests.
3. Embed the OpenGeni conversation (OpenGeniChat, or SessionConversation for
   one record) behind createSessionProxyHandler, and give the agent our data
   through our own authenticated tools.
4. Before building, ask me once about anything the repository does not
   answer, such as who can see a chat and whether the agent may change data.

Credentials are in the environment: OPENGENI_API_BASE_URL,
OPENGENI_ORGANIZATION_ID, OPENGENI_API_KEY. Keep the API key on the server.
```

To install the skill yourself:

<CodeGroup>

```bash npx
npx skills add Cloudgeni-ai/opengeni --skill opengeni-client --yes
```

```bash bunx
bunx skills add Cloudgeni-ai/opengeni --skill opengeni-client --yes
```

</CodeGroup>

The [OpenGeni plugin](/guides/developer-plugin) bundles this skill with `opengeni-setup`, which creates the organization and API key with you.

## What you get

- **A proxy route** at `/api/opengeni/*` that checks your existing user session.
- **The chat UI**: `<OpenGeniChat />`, or `<SessionConversation />` for one record, styled with your brand.
- **User onboarding**: each user gets access to their OpenGeni workspace.
- **Your tools**: an MCP server or OpenAPI integration so the agent can use your product's data as the signed-in user.
- **Tests** for the proxy and tenant isolation.
