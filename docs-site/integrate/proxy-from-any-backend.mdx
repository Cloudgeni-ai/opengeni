[`createSessionProxyHandler`](/embed-manually) is JavaScript. On any other backend, write the same relay in your own framework and render `<OpenGeniChat baseUrl="/api/opengeni" />` (or the full `SessionApp`) against it.

The relay forwards the signed-in user's requests to the Opengeni API as that user. Opengeni's permissions decide what each request may do; your relay only pins the workspace, adds the organization key and the user's identity, and keeps closed whatever your product does not offer.

## What to forward

Forward `/api/opengeni/v1/<path>` to `/v1/<path>` upstream, with the query string and body unchanged.

| Request                                                   | Rule                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Any method on `workspaces/{ws}` and `workspaces/{ws}/...` | Forward as the user. `{ws}` must equal the workspace your server resolved for the user; answer 403 for any other.                                                                                                                                                                                                                                                        |
| `GET config/client`                                       | Add `workspaceId={ws}`. In the response, add `workspaceId`, set `apiContractRevision` to the browser's `x-opengeni-api-contract`, drop `artifacts` (unless you serve the artifact viewer) and `sessionUsageLimits`, set `fileUploads.enabled: false` when you refuse uploads (for example for anonymous visitors), and set `modelSelection: false` if you fix the model. |
| `GET workspaces`                                          | Return only the resolved workspace from the upstream list.                                                                                                                                                                                                                                                                                                               |
| `GET access/me`                                           | Forward, then replace `workspaceGrants` with the user's grant for `{ws}` from `GET /v1/workspaces/{ws}/access/grant`, and drop `credential`.                                                                                                                                                                                                                             |
| Anything else                                             | 404.                                                                                                                                                                                                                                                                                                                                                                     |

Narrow the surface with the organization key's permissions and each member's permissions first: a request made as a user holds only the permissions both hold. Refuse any further routes your product keeps closed with a 404.

**If your server owns chat setup** (it builds the agent, tools and MCP servers for each chat), also:

- accept only `initialMessage`, `idempotencyKey`, file `resources`, and (unless you fix the model) `model`, `reasoningEffort`, `latencyMode` on `POST workspaces/{ws}/sessions`, and build the rest of the request on the server with your [privacy settings](/integrate/users-and-tenants#choose-who-shares-chats);
- refuse `PUT sessions/{sid}/{agent|tool-policy|skills|variable-sets|usage-limit|visibility}`, `POST sessions/{sid}/{active-sandbox|codex-account|forks}`, and `POST workspaces/{ws}/chat/completions`.

**Message rules** for `POST sessions/{sid}/events` (`user.message`), `steer` and `composer-draft/submit`: reject `mcpCredentialUpdates`, and always refuse `POST sessions/{sid}/mcp-credentials/rotate` and `session-imports` (imported history is stored as genuine transcript, so only your server may write it). If you fix the model, overwrite `model`, `reasoningEffort`, and `latencyMode` with your values rather than dropping them. Your server may add `modelContext` and `mcpCredentialUpdates` itself.

## Headers

Send these upstream, and nothing else from the browser:

```text
Authorization: Bearer <organization API key>
x-opengeni-external-actor: <percent-encoded JSON>
  {"mode":"external","identity":{"externalId":"<your user id>","source":"<your app>"}}
x-opengeni-api-contract: <copied from the browser's request>
Content-Type, Accept, Range, If-None-Match, If-Match, If-Modified-Since,
Last-Event-ID, x-opengeni-session-id, x-opengeni-correlation-id,
x-opengeni-chunk-*                         (copied from the browser when present)
```

Return upstream status codes, error bodies, and the `Content-Type`, `Content-Length`, `Content-Disposition`, `Content-Range`, `Accept-Ranges`, `ETag`, `Last-Modified`, `Retry-After`, `Content-Security-Policy`, `Cross-Origin-Resource-Policy` and `x-opengeni-*` headers unchanged; the SDK reads them. Add `Cache-Control: no-store` and `X-Content-Type-Options: nosniff`, and `Content-Security-Policy: sandbox` when upstream sends none.

## Security rules

- Authenticate the user on every request and derive the workspace and user id on the server.
- Reject any `{ws}` other than the resolved one.
- Reject path segments that decode to empty, `.` or `..`, or contain `/`, `\` or control characters, and percent-encode each segment again when you forward it.
- Apply your CSRF protection to every method except GET and HEAD.
- Cap request bodies you parse (1 MiB is plenty) and don't log bodies or keys.
- Stream request bodies, responses and SSE unbuffered, and close the upstream request when the browser disconnects.
- Store each tenant's workspace id. Create it once with `POST /v1/workspaces/external` (the SDK's `ensureWorkspace`). Users are added to it on their first request.

## Django example

```python
# urls.py: path("api/opengeni/<path:rest>", views.opengeni_proxy)
import json, os, re, urllib.parse

import httpx
from django.http import HttpResponse, JsonResponse, StreamingHttpResponse

API = os.environ["OPENGENI_API_BASE_URL"].rstrip("/")
KEY = os.environ["OPENGENI_API_KEY"]
SOURCE = "acme-app"

FORWARDED = {"content-type", "accept", "range", "if-none-match", "if-match",
             "if-modified-since", "last-event-id", "x-opengeni-api-contract",
             "x-opengeni-session-id", "x-opengeni-correlation-id"}
# Routes your product keeps closed, matched after workspaces/{ws}/.
REFUSED = [r"sessions/[^/]+/mcp-credentials/rotate", r"session-imports(/.*)?"]
RELAYED = {"content-length", "content-disposition", "content-range", "accept-ranges", "etag",
           "last-modified", "retry-after", "content-security-policy",
           "cross-origin-resource-policy"}

def upstream_headers(request, user_id):
    actor = {"mode": "external", "identity": {"externalId": user_id, "source": SOURCE}}
    headers = {
        "Authorization": f"Bearer {KEY}",
        "x-opengeni-external-actor": urllib.parse.quote(json.dumps(actor), safe=""),
    }
    for name, value in request.headers.items():
        if name.lower() in FORWARDED or name.lower().startswith("x-opengeni-chunk-"):
            headers[name] = value
    return headers

def opengeni_proxy(request, rest):
    user = request.user  # your auth; CsrfViewMiddleware covers every unsafe method
    if not user.is_authenticated:
        return JsonResponse({"error": {"code": "unauthorized"}}, status=401)
    ws = user.profile.opengeni_workspace_id  # resolved on the server
    path = rest.removeprefix("v1/")
    segments = path.split("/")
    if any(s in ("", ".", "..") or "\\" in s or not s.isprintable() for s in segments):
        return JsonResponse({"error": {"code": "route_not_allowed"}}, status=404)
    if segments[0] == "workspaces" and len(segments) > 1:
        if segments[1] != ws:
            return JsonResponse({"error": {"code": "workspace_not_allowed"}}, status=403)
        inner = "/".join(segments[2:])
        if any(re.fullmatch(pattern, inner) for pattern in REFUSED):
            return JsonResponse({"error": {"code": "route_not_allowed"}}, status=404)
    elif not (request.method == "GET" and path in ("config/client", "workspaces", "access/me")):
        return JsonResponse({"error": {"code": "route_not_allowed"}}, status=404)
    body = request.body if request.method not in ("GET", "HEAD") else None
    # Apply the message rules here; if your server owns chat setup, build the
    # full request for POST .../sessions. Scope workspaces and access/me to ws.
    headers = upstream_headers(request, str(user.id))
    url = f"{API}/v1/" + "/".join(urllib.parse.quote(s, safe="") for s in segments)
    if path == "config/client":
        params = {**request.GET.dict(), "workspaceId": ws}
    else:
        params = request.GET
    if path.endswith("/stream"):
        client = httpx.Client(timeout=None)
        upstream = client.send(
            client.build_request("GET", url, headers=headers, params=params), stream=True)

        def relay():  # closing the generator (browser gone) closes the upstream stream
            try:
                yield from upstream.iter_raw()
            finally:
                upstream.close()
                client.close()

        response = StreamingHttpResponse(relay(), status=upstream.status_code,
                                         content_type="text/event-stream")
        response["Cache-Control"] = "no-store"
        response["X-Accel-Buffering"] = "no"
        return response
    upstream = httpx.request(request.method, url, headers=headers, params=params,
                             content=body, timeout=60)
    if path == "config/client" and upstream.status_code == 200:
        config = upstream.json()
        config["apiContractRevision"] = request.headers.get(
            "x-opengeni-api-contract", config["apiContractRevision"])
        config["workspaceId"] = ws
        config.pop("artifacts", None)
        config.pop("sessionUsageLimits", None)
        return JsonResponse(config)
    response = HttpResponse(upstream.content, status=upstream.status_code,
                            content_type=upstream.headers.get("content-type", "application/json"))
    for name, value in upstream.headers.items():
        lower = name.lower()
        if lower in RELAYED or (lower.startswith("x-opengeni-") and lower != "x-opengeni-api-contract"):
            response[name] = value
    response["Cache-Control"] = "no-store"
    response["X-Content-Type-Options"] = "nosniff"
    if "content-security-policy" not in upstream.headers:
        response["Content-Security-Policy"] = "sandbox"
    return response
```

Run it under an ASGI or threaded server so open event streams don't block other requests.
