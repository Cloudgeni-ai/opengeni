A small server that serves an Opengeni agent through `createChatHandler` from `@opengeni/sdk/chat`. Connect your existing chat UI, or try it with `curl`. For a ready-made React UI, use [`SessionConversation`](/integrate/conversation-ui) instead.

## Run it

You need Bun, a repository checkout, and a full-access organization API key. The demo uses private chats, so **Only me chats** must be on in **Organization settings > Security & data**.

```bash
git clone https://github.com/Cloudgeni-ai/opengeni.git
cd opengeni && bun install
cd examples/chat-quickstart
cp .env.example .env.local   # set OPENGENI_API_KEY
bun run server
```

The demo workspace is created on first use, and user `u_42` is added to it on their first request.

Send a message:

```bash
curl -N http://127.0.0.1:4200/api/chat \
  -H 'Content-Type: application/json' \
  -H 'x-demo-user: u_42' \
  -H 'x-opengeni-conversation: c_1' \
  -d '{"message":"Hello"}'
```

`GET /api/chat` with the same headers returns the history, and `POST /api/chat/respond` answers a pending approval or question.

The `x-demo-user` header is for the demo only. A real product authenticates the user on the server.

## Formats

The handler streams its own chat chunks by default, and also speaks the Vercel UI message stream (`format: "vercel"`), OpenAI Chat Completions, and OpenAI Responses. See [Keep your existing chat UI](/integrate/existing-chat-ui).

[View the source on GitHub](https://github.com/Cloudgeni-ai/opengeni/tree/main/examples/chat-quickstart).
