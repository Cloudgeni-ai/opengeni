Coding agents integrating Opengeni into a product should start with the `opengeni-client` skill. It covers the default embed, onboarding, tools, isolation, background work, and verification.

## Install the skill

For Claude Code, Codex, Cursor, or ChatGPT, install the [developer plugin](/guides/developer-plugin). Otherwise, run this from the product repository root:

```bash
npx skills add Cloudgeni-ai/opengeni --skill opengeni-client --yes
```

`bunx skills add ...` works too. Or copy the directory with git:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/Cloudgeni-ai/opengeni /tmp/opengeni
git -C /tmp/opengeni sparse-checkout set .agents/skills/opengeni-client
mkdir -p .agents/skills && cp -R /tmp/opengeni/.agents/skills/opengeni-client .agents/skills/
```

The whole skill is also readable as one Markdown page: [`/reference/opengeni-client-skill.md`](/reference/opengeni-client-skill).

The skill is for the agent building the integration, not for the agent your customers talk to.

## Which source to trust

When sources disagree, trust them in this order:

1. **The live deployment.** `GET /v1/config/client` and `GET /v1/access/me` show what it supports and what the credential may do.
2. **The installed packages.** The types of `@opengeni/sdk` and `@opengeni/react` define the API you can call.
3. **The skill and the repository docs**, such as [`docs/product-integration.md`](https://github.com/Cloudgeni-ai/opengeni/blob/main/docs/product-integration.md).
4. **These pages.**
