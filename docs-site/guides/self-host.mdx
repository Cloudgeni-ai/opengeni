Opengeni is Apache-2.0: the API, web app, workers, Helm chart, and reference Terraform are all open source.

## What you run

| Component                      | Role                                                                               |
| ------------------------------ | ---------------------------------------------------------------------------------- |
| API                            | Public HTTP API: sessions, events, files, streaming                                |
| Web                            | The React console                                                                  |
| Control worker and turn worker | Temporal workers. Run both: one handles lifecycle, the other runs turns            |
| Postgres with pgvector         | Event store, history, and knowledge index                                          |
| Temporal                       | Orchestration                                                                      |
| NATS                           | Realtime fanout to API instances                                                   |
| Object storage                 | Files and sandbox archives: Azure Blob, AWS S3, or GCS                             |
| Sandbox backend                | Where sessions run: Docker, Modal, a cloud sandbox provider, or Connected Machines |

In production, use managed services or official charts for Postgres, Temporal, NATS, and object storage. The chart's built-in copies are for local and smoke testing.

## Install with Helm

Charts are published as OCI artifacts under `ghcr.io/cloudgeni-ai`. Each release's BOM lists the chart reference and image digests. Pin the chart to the version you run and keep secrets in a Kubernetes Secret:

```bash
OPENGENI_VERSION="<published-version>"
OPENGENI_CHART_OCI="oci://ghcr.io/cloudgeni-ai/charts/opengeni/opengeni"

helm upgrade --install opengeni "$OPENGENI_CHART_OCI" \
  --namespace opengeni \
  --create-namespace \
  --version "$OPENGENI_VERSION" \
  --set secret.existingSecret=opengeni-runtime
```

## Reference infrastructure

Terraform for Azure, AWS, and GCP lives under `deploy/terraform`. List the deployment profiles and plan one:

```bash
bun run deployment:profiles
bun run deployment:stack -- --profile gcp-managed
```

The plan lists the resources, dependencies, required secrets, and the deploy, verify, and destroy commands.

## Access modes

`OPENGENI_PRODUCT_ACCESS_MODE` sets how callers are identified:

| Mode         | Use                                                                      |
| ------------ | ------------------------------------------------------------------------ |
| `local`      | Local development with one `dev` user                                    |
| `configured` | Your product signs delegated tokens, or callers share one deployment key |
| `managed`    | Opengeni sign-up, organizations, API keys, credits, and limits           |

Outside local development, `configured` mode needs either `OPENGENI_DELEGATION_SECRET` (delegated tokens) or `OPENGENI_AUTH_REQUIRED=true` with `OPENGENI_ACCESS_KEY` (a shared key sent as `x-opengeni-access-key`). The shared key is a simple perimeter, not per-tenant access control. See the [security boundary](https://github.com/Cloudgeni-ai/opengeni/blob/main/docs/deployment.md#security-boundary).

## Credit coupons

With Stripe billing enabled, customers can redeem promotion codes when adding credits. You create and manage the codes in your own Stripe account. Set `OPENGENI_WEB_BASE_URL` if the console and API use different origins.

## Before you expose it

Put the deployment behind a gateway with:

- TLS
- Authentication for every user-facing route
- Rate and request-size limits sized for sessions, files, and SSE
- SSE support: buffering off, read and send timeouts of at least 3600 seconds
- Access logs

Review sandbox preparation profiles and environment allowlists: they decide which host credentials reach a sandbox.

<Warning>
  Some migrations require stopping every old API and worker first, and the old image must not be
  restarted afterward. Read the upgrade notes in the [deployment
  guide](https://github.com/Cloudgeni-ai/opengeni/blob/main/docs/deployment.md) before every
  upgrade.
</Warning>

## Console links

The console's Help entry opens the public Opengeni docs. Set `OPENGENI_DOCUMENTATION_URL` to your own docs, or `none` to hide it.

For link previews in Slack and other chat tools, set `OPENGENI_PUBLIC_BASE_URL` to the public address, and `OPENGENI_WEB_BASE_URL` to the console origin if it differs from the API.
