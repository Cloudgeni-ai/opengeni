The **OpenGeni** plugin has three public skills:

- `build-with-opengeni` builds products and local demos, with the full client
  guide as supporting reference material.
- `offload-to-opengeni` runs work in an OpenGeni session in the cloud.
- `opengeni-setup` sets up SDK/REST access through your coding agent's own tools.

The plugin also connects your coding agent to your OpenGeni organization through
the OpenGeni MCP server (`https://app.opengeni.ai/v1/mcp`), so it can find and
run any OpenGeni action. The first use opens a browser sign-in where you choose
what the agent may access; there is no key to paste. The skills guide the
coding agent building your product, not your product's customer-facing agent.

## Install

For Claude Code or Codex, add the `Cloudgeni-ai/opengeni` marketplace and install
**`opengeni@opengeni`**. For Cursor, import that repository through
**Customize → From GitHub Repository**, then install **OpenGeni**. Supported
ChatGPT desktop marketplace surfaces can also use the portable package;
availability depends on the surface and workspace permissions.

[Copy the install commands and local-checkout instructions](https://github.com/Cloudgeni-ai/opengeni/blob/main/docs/developer-plugin.md).
The guide records official formats verified October 1, 2026 and native-loader
checks. This plugin has not been published to the universal public directory.

Installation asks no questions. To sign in ahead of time, run `/mcp` in Claude
Code and select `opengeni`, or run `codex mcp login opengeni` in Codex.

## Use

Ask your coding agent to set up OpenGeni access, build an OpenGeni-powered
product, or inspect and change your OpenGeni organization. In Claude Code,
invoke `/opengeni:opengeni-setup` or `/opengeni:build-with-opengeni`. The nested client guide is supporting material,
not a separate fourth plugin skill.

Continue with [Embed with your coding agent](/embed-with-a-coding-agent) or
[For AI agents](/reference/for-ai-agents).
