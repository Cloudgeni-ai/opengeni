Third-party notices for the shell tools Opengeni ships
======================================================

Opengeni ships unmodified official release executables of ripgrep (rg) and
jq with its own runtime tools, so commands can use them where the system has
none. A system rg or jq on PATH always takes precedence.

- ripgrep 15.2.0, https://github.com/BurntSushi/ripgrep, MIT OR Unlicense.
  Its release executables statically include PCRE2 10.45 (BSD-3-Clause WITH
  PCRE2-exception).
- jq 1.8.2, https://github.com/jqlang/jq, MIT (with the further notices in
  its COPYING below). Its release executables statically include Oniguruma
  (BSD-2-Clause).

The licence texts follow, copied verbatim from the release archives and
source tags.
